# Exam Prep — 30-Day Study Pack (ทบทวนก่อนสอบ 30 วัน)

ชุดอ่าน–ทบทวนก่อนสอบ **14 หัวข้อ** ภาษาไทย ออกแบบสำหรับทบทวน 1 เดือน: อ่านเข้าใจ → ท่อง "ต้องจำ" → ระวังกับดักข้อสอบ → self-check ปิดหน้า

**Live site:** https://misternay.github.io/exam-prep-30-days/

## เนื้อหา

| ไฟล์ | รายละเอียด |
|---|---|
| `index.html` | แผน 30 วัน (D1–D30), รูทีนรายวัน 60–90 นาที, กติกา retrieval/spacing/interleaving |
| `sheets/01–14.html` | ชีทสรุปรายหัวข้อ: Database/SQL · Software Design · Security · Context Engineering · Skills · Programming · Version Control · CI/CD · Quality Engineering · Docker · AI Coding Workflow · Agents/Harness · Software Development · LLM |
| `flashcards.csv` | การ์ดท่องจำ 162 ใบ (10–14 ใบ/หัวข้อ) — import เข้า Anki ได้ (Front/Back/Tags) |
| `assets/style.css` | ธีมกลางของทุกหน้า (light/dark/print) |

## วิธีใช้

1. เปิด `index.html` (หรือเว็บ live) แล้วทำตามตาราง 30 วัน
2. ทุกชีทมี 4 ส่วน: 📖 ต้องเข้าใจ · ⭐️ ต้องจำ · ⚠️ กับดักข้อสอบ · 📝 Self-check
3. ทวนการ์ดแบบ spaced repetition: D+1, D+7, D+21
4. พิมพ์เป็น PDF ได้ (print stylesheet พร้อม) — self-check จะกางเฉลยให้ในเวอร์ชันพิมพ์
