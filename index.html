วิธีใช้ (อ่านก่อนเริ่ม)

แต่ละ sheet มี 4 ส่วนเหมือนกันทุกไฟล์:

  1. ต้องเข้าใจ — concept อ่านให้เข้าใจ (อ่าน ~30–40 นาที)
  2. ต้องจำ — ตาราง/รายการที่ข้อสอบออกบ่อย ท่องให้ได้
  3. กับดักข้อสอบ — จุดที่คนมักตอบผิด
  4. Self-check — ปิดหน้า ตอบเองก่อน แล้วค่อยกางเฉลย (นี่คือส่วนที่ทำให้จำได้จริง)
กติกา 4 ข้อ (สำคัญกว่าอ่านเยอะ)
  1. Retrieval ก่อนเสมอ — อย่าเพิ่งอ่านซ้ำ พยายามนึกก่อน 1–2 นาที การนึกไม่ออกแล้วค่อยเปิด คือจังหวะที่สมองจำฝังแน่น
  2. เว้นวรรค (spacing) — เป้าหมาย: ทวน D+1 (การ์ดรายวัน) → ทวนรวมประจำสัปดาห์ → full review สัปดาห์ที่ 4; ถ้าตารางเลื่อน ให้ชดในวัน buffer (D21/D27) — ห้ามข้ามวันทบทวนรวม
  3. สลับหัวข้อ (interleaving) — วันทบทวนให้สุ่มสลับหัวข้อ ไม่ทวนทีละหัวข้อรวดเดียว
  4. Mock exam ปิดหนังสือ — D26/D28 เขียนคำตอบเอง จับเวลา ถ้าเปิดดู = เลิกนับว่า mock

รูทีนรายวัน 60–90 นาที

  1. 10 นาที — ทวนการ์ดที่ถึงกำหนด (D+1 จากเมื่อวาน)
  2. 30–40 นาที — อ่าน sheet ใหม่ จบแล้วปิดหน้า เขียนสรุป 5 บรรทัดจากความจำ
  3. 10–15 นาที — ทำ self-check ทุกข้อ ปิดหน้า เขียนคำตอบก่อนเปิดเฉลย
  4. 5 นาที — การ์ดไหนยังตอบผิด = ติดดาวไว้ พรุ่งนี้ทวนซ้ำ

ตาราง 30 วัน

W = week · ตัวเลขในวงเล็บ = เลขหัวข้อที่ทวน · “ทวน” = ทวนการ์ด + self-check เก่า ไม่ต้องอ่านเนื้อซ้ำทั้งหน้า

W1 — พื้นฐานวิศวกรรม
D1 · Programming ครึ่งแรก (06) — โครงสร้างข้อมูล, Big-O, อัลกอริทึม
D2 · Programming ครึ่งหลัง (06) — OOP/FP, concurrency, กับดักภาษา + ทวนการ์ด D1
D3 · Software Development (13) — SDLC, Agile/Scrum, requirements
D4 · Software Design (02) — SOLID, patterns, architecture
D5 · Database/SQL ครึ่งแรก (01) — model, ACID, isolation levels
D6 · Database/SQL ครึ่งหลัง (01) — index, joins, window functions + ทวน (02)
D7 · ทบทวน W1 — สุ่ม self-check จาก 06, 13, 02, 01 (ปิดหน้า)
W2 — งานวิศวกรรมจริง
D8 · Version Control (07) — Git model, merge/rebase, undo
D9 · CI/CD (08) — pipeline, deploy strategies
D10 · Quality Engineering (09) — pyramid, TDD, test doubles
D11 · Docker & Containerize (10) — image/layer, Dockerfile, compose
D12 · Security ครึ่งแรก (03) — CIA, OWASP Top 10, authN/authZ
D13 · Security ครึ่งหลัง (03) — attacks & defenses, secure SDLC + ทวน (07, 08)
D14 · ทบทวน W2 + สลับหัวข้อ W1 — สุ่ม 3 หัวข้อจาก 10 หัวข้อแรก
W3 — AI Fundamentals
D15 · LLM (14) — token, training stages, params
D16 · Context Engineering (04) — context window, RAG, compaction
D17 · Skills (05) — โครงสร้าง skill, เขียนยังไง, ต่างจาก memory/RAG
D18 · Coding Workflow (11) — plan→verify loop, spec-driven, review AI
D19 · Agents / Harness (12) — loop, tool calling, MCP, guardrails
D20 · ทบทวน AI ทั้งหมด — เขียน mind map: LLM → Context → Skills → Coding → Agents (จากความจำ)
D21 · Buffer / จุดอ่อน — เลือกหัวข้อที่ยังไม่แม่นจาก 14 หัวข้อ อ่านเฉพาะ “ต้องจำ” + ทำ self-check ซ้ำ
W4 — รวมและสอบจำลอง
D22 · Full review A — 06, 13, 02 (สุ่มคำถามข้ามหัวข้อ)
D23 · Full review B — 01, 07, 08
D24 · Full review C — 09, 10, 03
D25 · Full review D — 14, 04, 05, 11, 12 (ตระกูล AI)
D26 · Mock exam 1 — ปิดหนังสือ เขียนคำตอบเอง จับเวลา
D27 · ตรวจ mock 1 — ทุกข้อที่ตอบผิด กลับไปอ่าน “ต้องจำ” ของหัวข้อนั้น + เพิ่มการ์ดใหม่
D28 · Mock exam 2 + ทวนการ์ดที่ยังผิด
D29 · Final pass — สแกน “ต้องจำ” ทั้ง 14 ไฟล์ + การ์ดทั้งหมด
D30 · เบา — ดูสารบัญ/index ทุกหัวข้อรอบเดียว + พักผ่อนให้เต็มที่

การ์ดท่องจำ (flashcards.csv)

ไฟล์ flashcards.csv เป็น CSV: Question,Answer,Tags ใช้ได้ 2 ทาง:

  1. Anki: File → Import → เลือกไฟล์ → แยกฟิลด์ด้วย comma → แมป Field 1 = Front, 2 = Back, 3 = Tags → Import
  2. ไม่ใช้แอป: เปิดใน Numbers/Excel แล้วสลับคอลัมน์ถาม–ตอบเอง ทวนวันละ 10 นาทีตามรูทีน

การ์ดมี 10–14 ใบต่อหัวข้อ (รวม 162 ใบ) ใช้ทวน D+1 และวันทบทวน — แต่ละวันไม่ควรใช้เกิน 15 นาที

ถ้าเวลามีไม่ครบ 30 วัน ให้ทำตามลำดับความสำคัญนี้ก่อน: 1) “ต้องจำ” + self-check ทุกไฟล์ 2) ตาราง ACID/isolation, SOLID, OWASP, test pyramid, deploy strategies, ข้อเปรียบเทียบใน AI ทั้ง 5 หัวข้อ 3) ที่เหลือค่อยอ่านประกอบ — ข้อสอบแนวความเข้าใจมักออกจากส่วนนี้

มีคำถามตรงไหนใน sheet ไหน ถามผู้ช่วยได้เลยระหว่างอ่าน — จะอธิบายเพิ่ม/ยกตัวอย่างโจทย์ให้ได้ทุกหัวข้อ
